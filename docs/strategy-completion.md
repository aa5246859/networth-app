# 策略結單與完成紀錄（2.4.33）

## 使用方式

1. 在長線或短線策略新增、編輯時，分別填寫「目標」與「預期持有時間」。舊版合併內容保留在目標欄，編輯時會提示可自行拆分。
2. 執行完後展開策略，按「完成結單」，選獲利、虧損或損益兩平，填寫幣別、日期與備註。金額可留空，留空不會被當作 0；填寫時使用正數，正負號由結果決定。
3. 儲存後自動切到「已完成」並展開該筆。卡片在收合時也會顯示結果、金額與結單日期。
4. 「編輯結單」可修正結果；「編輯」可修正原策略，結單紀錄仍保留。已完成策略不需刪除。舊版已結束但沒有結果的策略可以補填結單。

## 資料與分享

- 原策略 ID、建立時間、內容、指定分享對象、參與及已讀紀錄保留。編輯或結單會更新內容版本，已讀確認依原本規則重新計算。
- 結單結果屬於策略作者的紀錄，只有原有獲授權的策略觀看者可以查看；朋友介面維持唯讀。
- 結單後沿用既有策略更新通知。通知開啟時會切到正確長短線及已完成清單，展開對應策略。
- 此為策略回顧紀錄，不會替使用者下單，不會自動增加或扣除持倉、歷史資產或總覽金額，避免重複計算。
- 金額儲存為非負絕對值與獨立結果，幣別限定 TWD、USD；不同幣別不混合加總。
- 新版 JSON 備份為版本 3，保留持有時間與結單結果；可匯入舊版 1、2。匯入策略維持私人，分享授權與讀者名單不隨備份移轉。
