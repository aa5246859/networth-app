# 策略結單與自動已讀（2.4.34）

## 使用方式

1. 長短線策略的「目標」與「預期持有時間」分開填寫，舊內容保留在目標欄。
2. 執行完後展開策略，按「完成結單」，選獲利、虧損或損益兩平，填寫日期與選填備註。不需填金額或幣別。
3. 儲存後切到「已完成」並展開該筆。收合卡片顯示結果與日期；完成清單顯示各結果的筆數。
4. 「編輯結單」可修正結果；「編輯」可修正原策略，結單紀錄仍保留。舊版已結束的策略可以補填結果。

## 分享、已讀與通知

- 朋友展開策略，交易理由實際進入畫面並短暫停留後，自動記錄這次版本的已讀。收合卡片、背景分頁、被視窗遮住的內容不計；作者不會替自己產生讀者紀錄。
- 策略更新後，觀看者再次看到展開的新版內容，才記錄新版已讀；不影響既有參與／暫不參與選擇。
- 自動同步失敗時在原位置提示，重新展開或回到 App 時重試，避免連續跳錯誤訊息。重複畫面更新不會重複寫入同一版本。
- 已分享策略結單後，沿用指定分享對象和手機通知偏好發送通知。標題顯示「策略已結單 · 獲利／虧損／損益兩平」，內文顯示策略名稱及標的。舊紀錄未填結果時只顯示已結單。
- 點通知會切到正確長短線的已完成清單，展開對應策略。私人策略不通知，撤回授權或未被選取的人不會收到。
- 通知實際出現時間與顯示方式仍依手機的通知權限、專注模式與系統排程決定。

## 資料相容

- 保留原策略 ID、建立時間、內容、分享對象與參與紀錄。
- 結單供策略回顧，不會自動更動持倉、歷史資產或總覽金額。
- 舊金額資料保留以相容既有備份，不再顯示或要求輸入；修正相同結果的日期與備註不會清除舊值。
- JSON 備份維持版本 3，保留持有時間與結單結果，可匯入版本 1、2。匯入維持私人，不移轉分享授權或讀者名單。
- 本版沿用已發布的 Firestore 規則，不需再發布規則。通知 Worker 更新時保留既有資料庫、變數及服務帳戶綁定。
