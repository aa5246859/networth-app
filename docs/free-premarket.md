# 免費美股盤前報價（2.4.31）

## 行為

- 沿用持倉與共享持倉原本每分鐘的自動更新，以及手動更新報價按鈕。
- 在美東平日 04:00–09:30 查詢 Yahoo Finance 公開圖表的盤前一分鐘資料，不需新增 API 金鑰、付費訂閱或試用。一般時段繼續使用原本 Finnhub。
- 後端依來源的實際盤前起訖時間檢查交易日、夏令時間及有效成交時間；只有當前盤前時段內的 USD 股票／ETF 正數價格才可使用。
- 比較盤前與一般來源的成交時間，採用較新的價格。來源失敗或僅回傳更舊價格時保留最後成功報價，不回填為零，也不拿查詢時間冒充成交時間。
- 市值、損益、整合持倉及總覽沿用既有公式；股數、成本和歷史紀錄均不因報價變更而修改。
- 原本行情文字顯示「盤前行情」或「盤前均價」。保留既有排版及所有按鈕位置。

## 免費來源的限制

Yahoo Finance 公開圖表不是保證可用的商用即時資料 API，可能延遲、限流或改版。App 不宣稱逐筆即時；來源明確標示「可能延遲」，並保留真正的資料時間。

固定上游僅接收有效股票代號；單次最多 20 個、最多 4 個並行查詢。公開快取只包含股票價格，保留 30 秒，沒有帳號、持倉數量、成本或通知資訊。來源查詢有逾時及回應大小上限。帳號與通知端點沿用原本驗證。

## 部署與查驗

先部署既有 Cloudflare Worker 的 `worker.js` 和 `premarket.js`，保留所有綁定、金鑰、用量模式及每日排程，再發布前端。
